# Computer Networks Laboratory

A collection of laboratory experiments, practical implementations, and supporting resources completed as part of the **Computer Networks Laboratory (CSBB 301)** course at the **National Institute of Technology Delhi (NIT Delhi)**.

This repository documents the practical study of computer networking concepts, including network devices, IP addressing, LAN configuration, routing protocols, NAT, TCP/UDP communication, socket programming, and DHCP.

## Experiments

| No. | Experiment | Description |
|:---:|---|---|
| 01 | Network Cables | Study of different types of network cables and their applications. |
| 02 | Basic Network Commands | Practical use of commands such as `ping`, `ipconfig`, `tracert`, `netstat`, and `nslookup`. |
| 03 | Network Devices | Study of hubs, switches, routers, modems, bridges, and other networking devices. |
| 04 | Network IP Addressing | Study and configuration of IPv4 and IPv6 addressing. |
| 05 | Local Area Network (LAN) | Establishment and testing of communication between computers in a LAN. |
| 06 | Router Configuration | Basic router configuration using Cisco Packet Tracer. |
| 07 | Peer-to-Peer Network | Establishment of a peer-to-peer network connection. |
| 08 | Network Address Translation (NAT) | Examination and configuration of NAT in a network environment. |
| 09 | Routing Protocols | Simulation and study of static routing, RIP, EIGRP, and OSPF. |
| 10 | TCP and UDP | Implementation and observation of connection-oriented and connectionless communication. |
| 11 | Socket Programming | Study of socket programming and the client-server communication model. |
| 12 | Network Tools and Technologies | Exploration of network simulation, emulation, monitoring, and management tools. |
| 13 | DHCP Configuration | Implementation and configuration of a Dynamic Host Configuration Protocol (DHCP) server. |

## Tools and Technologies

The practical work in this repository involves the following tools and technologies:

- **Cisco Packet Tracer** – Network topology creation, device configuration, and simulation.
- **Python** – Socket programming and client-server communication.
- **TCP/IP** – Understanding and implementation of network communication protocols.
- **Cisco IOS CLI** – Basic router and network device configuration.
- **Networking Commands** – Diagnostic and troubleshooting utilities.
- **Network Protocols** – TCP, UDP, IP, NAT, DHCP, RIP, EIGRP, and OSPF.

## Objectives

Through these laboratory experiments, the following concepts and practical skills are explored:

- Understanding network architectures, devices, and transmission media.
- Configuring IP addresses and establishing local network connections.
- Working with routers, switches, and basic network topologies.
- Understanding routing mechanisms and network address translation.
- Comparing TCP and UDP communication.
- Developing client-server applications using Python socket programming.
- Understanding DHCP and other essential network services.
- Using network simulation tools to observe and troubleshoot communication.

## Getting Started

To explore this repository:

1. Clone the repository:

   ```bash
   git clone https://github.com/random-guy-git/Computer-Networks-Labwork.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Computer-Networks-Labwork
   ```

3. Open the required experiment from the `Lab-Reports` directory.

4. Open the corresponding `.pkt` file using Cisco Packet Tracer to examine the network topology and configuration.

5. For Python socket programming experiments, ensure Python is installed and run the server and client scripts from separate terminals.
